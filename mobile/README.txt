PHONE INSTALL
=============
1. Copy the mobile/ folder to your phone (or only mobile/index.html).
2. Open index.html in Chrome (about 17-18 MB - all pages inside one file).
3. Tap the menu (menu icon) to switch Words / HSK / TOCFL / characters / pronunciation / tones.
4. Do NOT open hsk.html, hsk2.html, etc. separately from a file manager. Sharing a
   single file with the browser uses a content:// address that cannot reach the
   files next to it; those pages will say so and dim their links.

Rebuild on PC: python scripts/build_mobile_pack.py && python scripts/build_offline_app.py
